# OM Notes — 作業管理の学習室

作業管理（Operations Management）第1〜5章を学ぶ、日本語対応の静的Webアプリです。

現在のトップ画面は、添付教科書PDFに基づく**新規150問（各章30問）**の「教科書クイズ」です。問題・選択肢は英語、回答後の解説は日本語です。章別の練習と全章50問（各章10問）を用意し、5・10・20・50・全問の設定、誤答復習にも対応しています。旧87問のDiscussion教材とその進捗も別に残しています。出典と検証方法は [PDF版クイズの説明](docs/PDF_QUIZ.md) を参照してください。React 19 + TypeScript + Vite。外部API、外部フォント、サーバー、データベースは使用しません。

## 起動

Node.js 22以降（この環境では24.19.0）、npmを使用します。

```sh
cd /workspace/mochimochi
npm install
npm run dev
```

Viteが表示するポートで開きます。開発サーバーは `0.0.0.0` にバインドします。

## ビルド・静的ホスティング

```sh
npm run build
npm run preview
```

`dist/` 全体を静的ホスティングに配置してください。`base: './'` のためサブディレクトリ配信に対応し、履歴ルーティングの書き換え設定は不要です。サーバー側処理やAPIキーは不要です。`file://` での直接実行ではなく、HTTP/HTTPS配信を使用してください。

## Discussion教材の機能

- CH1〜CH5の章タブ、章別の学習進捗、全体の達成率
- 全87問の英語原文・日本語訳を常時表示
- 学習用解答例・詳しい解説・選択式の注意点・繁體中文記述例をまとめて開閉
- 各問の「覚えた」「要復習」。同じボタンをもう一度押すと指定を解除
- 章別・全章混合の英語4択小テスト（5・10・20問・全問）
- 1問ごとの採点・教材による解説、得点・回答一覧・再挑戦
- 手動の「要復習」と小テストの誤答をまとめた復習モード、苦手限定クイズ
- 全章の6項目を対象とする英語・日本語・繁體中文キーワード検索
- localStorageへの自動保存、再読み込み後の復元、他タブからの変更反映

クイズで誤答すると「要復習」になり、正解しても自動で「覚えた」にはなりません。教材を確認して「覚えた」を押すと苦手リストから外れます。手動で「要復習」を解除しても、未解消のクイズ誤答があれば復習リストに残ります。問題数が指定数に満たない場合は対象の全問を出題し、重複はしません。正答位置は毎回シャッフルし、A〜Dの登場数の差を最大1に保ちます。

進捗はこのブラウザ・この配信元の `om-notes-progress-v1` に保存されます。端末間同期はありません。ブラウザデータの削除で進捗も消えます。保存が拒否された場合は画面に表示します。

## 教材の出典と完全性

指定された `operations_discussion_ch1-5_detailed_bilingual.zip` は作業フォルダに存在しませんでした。実際に添付された `codex_operations_ch1-5_full.md` を使用しています。この点は実装前に報告しました。ZIPとの同一性、出版社の原本との一致は検証できていません。

原本は [public/materials/codex_operations_ch1-5_full.md](public/materials/codex_operations_ch1-5_full.md) にバイト単位で変更せず保存しています。画面下部からダウンロードできます。原本内の学習方法などは参考資料として扱い、添付文書の記述をアプリ制作の指示として実行していません。

| 章 | 問題数 | 6必須項目 |
| --- | ---: | --- |
| CH1 | 17 | 全問あり |
| CH2 | 15 | 全問あり |
| CH3 | 19 | 全問あり |
| CH4 | 19 | 全問あり |
| CH5 | 17 | 全問あり |
| 合計 | **87** | **522項目** |

`src/data/material.json` は原本から各項目をそのまま抽出したものです。Markdownの見出しと区切り線・前後の空白だけを構造化し、内容の省略・翻訳の修正・原文の書き換えは行っていません。

```sh
npm run validate:data
# 原本から表示データを再生成する場合:
python3 scripts/prepare_material.py
```

表示データと原本の全87問・6項目の一致、問題番号、空項目、選択肢データの網羅性・重複を検査します。Python 3が必要です。詳細は [教材検証記録](docs/MATERIAL_AUDIT.md) を参照してください。

### 解答と小テスト

日本語訳・模範解答・詳しい解説・繁體中文記述例は**学習用資料であり、出版社公式の解答ではありません**。アプリにも明記しています。

小テストは教材の各問の要点を確認するために追加したものです。小テストの正答は教材の日本語解答例を英訳したものです。`src/data/quiz-en.json` に全87問の英語解答と各問専用の英語誤答3つを別管理しています。選択肢・採点後の解答・結果一覧の解答は英語で、詳しい解説と選択式の注意点は教材の日本語を表示します。英訳はアプリ用の学習資料であり出版社公式の解答ではありません。以前の日本語誤答データは `src/data/distractors.json` に保持しています。誤答は用語の取り違え、因果・比較の逆転、教材が指摘する誤解などです。教材の原文や解答に誤答データを混ぜていません。複数の小問がある設問でも、4択は要点の確認であり、記述式の完全な代替ではありません。採点後は教材の詳しい解説と選択式の注意点を表示します。原本自体の説明に不足や誤りがあっても、この実装では原本を勝手に訂正していません。

## テスト

```sh
npm run validate:data
npm run build
npx playwright install chromium
npm test
```

システムにChromiumがインストールされている場合:

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm test
```

テストは開発版ではなく `dist/` のプレビューサーバーを起動して実行します。実施結果は [テスト結果](docs/TEST_RESULTS.md)、テスト本体は [tests/app.spec.ts](tests/app.spec.ts) を参照してください。iPhone相当のChromiumエミュレーションと、iPhone Safari実機は区別しています。

## 主なファイル

- `src/main.tsx` — 学習画面、進捗、検索、クイズと採点
- `src/style.css` — モバイル対応レイアウト、ローカルの多言語フォント指定
- `src/data/material.json` — 教材6項目の完全な構造化データ
- `src/data/quiz-en.json` — 87問分の英語解答と英語の誤答選択肢
- `src/data/distractors.json` — 以前の日本語誤答選択肢（保存のみ）
- `public/materials/` — 無変更の教材原本
- `scripts/prepare_material.py` — 変換と照合
- `tests/app.spec.ts` / `playwright.config.ts` — E2Eテスト

外部通信を使わずに動作しますが、アプリをHTTPで読み込むための配信は必要です。PWAのオフラインキャッシュは実装していません。
